#gearHidden=防具・服・兜を非表示にする

mod.io 登録メモ: {{name}}

cks（Core Keeper スキン作成ツール）で書き出した MOD を、mod.io の Web サイトで登録するときの控えです。
このツールは mod.io へは登録しません。

■ 書き出した MOD
  名前            {{name}}
  版              {{version}}
  装備の見え方    {{gear}}
  上げるファイル  {{zipFile}}
  ロゴ            {{logoFile}}
  ゲームの版      {{gameVersion}}
  識別子          {{id}}（guid {{guid}}）
  識別子は書き出すたびに新しく付きます。別々に書き出した zip は、それぞれ別の MOD として登録できます。

■ 新しい MOD として登録する
  1. https://mod.io/g/corekeeper を開いてログインし、右上の「Add」を押して「Mod」を選びます（https://mod.io/g/corekeeper/m/add）。
     mod.io のアカウントのメールアドレスを確認済みにしておく必要があります（未確認だと登録の画面が出ません）。
     手順 2〜7 は、最初の段（Mod profile）の欄です。
  2. Mod name（名前）: {{name}}
     Profile URL（MOD のページの URL の末尾）: 英小文字・数字・ハイフンで 50 文字まで（例: my-knight-skin）。
     名前に英数字が無いと、ここは自動では入りません。自分で入れてください。
  3. Summary（要約。250 文字まで）: 次の日本語か英語のどちらか 1 行を貼ります（両方を貼ると 1 段落につながり、250 文字を超えることがあります）。
       自分の操作キャラクターの見た目を「{{name}}」に差し替えます。見た目だけの MOD です。Core Keeper スキン作成ツール（cks）で作りました。
       Changes your own player character's look to "{{name}}". Cosmetic only. Made with Core Keeper Skin Maker (cks).
  4. Mod listing image（ロゴ）: {{logoFile}}（1280×720）
     mod.io の条件は png か jpg、512×288 以上、8MB まで、16:9 推奨です。自分で用意した画像でもかまいません。
  5. Tag selection（タグ）: 次の 4 つを選びます。
       Game Version      {{gameVersion}}
       Access Type       Script
       Application Type  Client
       Type              Visual
     Game Version が無いと、遊ぶ人には起動時に、この版に対応していないという警告が出て、「ロードする」（英語の表示では Load anyway）を選ばない限り読み込まれません。
     Access Type を Asset にすると、MOD のスクリプトが動きません。
  6. Description（説明）の例:
       自分の操作キャラクターの見た目を「{{name}}」に差し替えます（どのキャラクターで遊んでも）。
       装備の見え方: {{gear}}（手に持つ武器や道具は常に見えます）。
       他のプレイヤーの画面には反映されません。見た目を変える MOD は、同時に 1 つだけ有効にしてください。
       Core Keeper スキン作成ツール（cks）で作りました: https://github.com/utausnskareshi/corekeeper-mod
  7. Mod visibility（公開の設定。日本語の表示では「可視性」）: Public（公開）か Private（非公開）を選びます。初期値は Public です。
     Core Keeper の mod.io には（2026-10 時点で）公開前の承認が無いため、Public のまま手順 8 でファイルを公開すると、その時点で誰でも見られるようになります。
     公開の設定は、後から MOD の編集画面で変えられます。
     ここまで入れたら「Create Mod」を押します（MOD のページが作られます）。
     続く Add media（ギャラリー画像。任意）、Dependencies（依存する MOD）、表示されれば Reuse permissions の段は、何も入れずに次へ進んでかまいません。
     ロゴは入れ直さなくてよく、この MOD は他の MOD を必要としません。
  8. Upload file(s) の段の File manager で {{zipFile}} を選び、Version（版）に {{version}} を入れます。
     「I agree to the terms and privacy policy」（規約への同意）にチェックを入れ、「Upload & publish」（公開するほうのボタン）で上げます。
     「Upload & keep as draft」（下書き）で上げたファイルは今の版にならず、ゲームに届きません（ファイルの一覧の「Publish」で後から今の版にできます）。
     公開せずに置いておきたいときは、下書きではなく手順 7 の Private を使ってください。

■ 登録した MOD を更新する
  その MOD のページの File manager で、新しく書き出した zip を上げます。
  Version にはこの zip の版（{{version}}）を、Changelog には変更点を入れます。{{version}} が前に上げた版と同じなら、版を上げて書き出し直してください（ゲームのログに出る版がこの値になります）。
  規約への同意にチェックを入れて「Upload & publish」で上げると、そのファイルが今の版になり、購読している人には自動で更新が届きます。
  下書き（Upload & keep as draft）で上げたファイルは、ファイルの一覧で「Publish」を押すまで届きません。
  書き出すたびに MOD の識別子（name・guid）が新しくなるため、更新した後は、遊ぶ人が MOD メニューで並べた読み込み順と「ロードする」の選択が、この MOD について初期の状態に戻ります（購読と有効の状態は引き継がれます）。
  「Add」→「Mod」で新しく登録すると、別の MOD になります（ゲーム内では両方とも選べます）。

■ ゲーム内で使う
  ・ゲームの MOD メニュー、または mod.io の Web で購読して有効にし、ゲームを再起動します。
  ・掛かるのは、遊ぶ人自身の操作キャラクターだけです。他のプレイヤーには掛かりません。
  ・cks で書き出した MOD を 2 つ以上有効にすると、読み込み順で先の 1 つだけが掛かります。
  ・cks の「ゲームへ配置」で絵を置いたキャラクターでは、そちらの絵が優先されます。
    mod.io の MOD の絵を確かめるときは、cks の「ゲームから削除」でそのキャラクターから外してください。

■ ゲームの版が上がったら
  ゲームは、タグの Game Version とゲームの版の先頭 3 つの数（1.3.0 など）だけを比べます。
  先頭 3 つの数が変わったとき（例: 1.3.0 → 1.3.1）は、mod.io にその Game Version のタグができたら、MOD のページでタグを編集して足してください。
  足さないと、遊ぶ人には起動時に非対応の警告が出て、「ロードする」を選ばない限り読み込まれません。
  警告で「無効にする」を選んだ人では MOD が無効になり、タグを足した後も、その人がゲームの MOD メニューで有効にし直すまで読み込まれません（警告には MOD の名前ではなく識別子 {{id}} が出ます）。
  4 つ目の数だけが変わったとき（例: 1.3.0.4 → 1.3.0.5）は、タグはそのままで読み込まれます。
  見た目が崩れるときは、新しい版の cks で書き出し直してください。

■ 登録の前に
  ・自分で描いた絵、または使う権利のある絵だけを使ってください。他の人の作品やキャラクターは使えません。
  ・成人向けの内容（露出の多い服など）は、Core Keeper の mod.io の決まりで削除の対象です。
  ・cks の「取得」で取り込んだ見た目には、ゲームの絵が含まれます。
    取得した見た目を公開してよいかを Pugstorm は示していません。公開するかはご自身で判断してください（Pugstorm は公開された MOD を削除できます）。
  ・Core Keeper の Mod SDK の規約では、MOD を営利目的で配布することは認められていません。
